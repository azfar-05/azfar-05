## Projects

**[CauseTrace](https://github.com/azfar-05/cause-trace)** — Failure Investigation & Root-Cause Analysis

Correlates CI stack traces with Git history to rank commits by regression likelihood. Signals — file overlap, line proximity, caller–callee propagation, recency — are explicit and inspectable. LLM reasoning generates grounded causal explanations from ranked evidence, not freeform guesses.

`Python` · `GitPython` · `GitHub Actions` · `OpenRouter API`

---

**[SEFI](https://github.com/azfar-05/sefi)** — Software Engineering Failure Intelligence

Full-stack CI/CD analytics platform that surfaces failure trends, flaky tests, regression-inducing commits, and MTTR from pipeline data. Includes a commit DAG with recursive CTE ancestry traversal and a React/TypeScript dashboard with developer-level filtering.

`Node.js` · `Express` · `PostgreSQL` · `React` · `TypeScript`

---

**[Machine Failure Prediction](https://github.com/azfar-05/machine-failure-prediction)** — Industrial ML

Compared 8 classifiers on operational failure data, evaluated across ROC-AUC, F1, and recall. Deployed as an interactive Streamlit dashboard for real-time prediction and model diagnostics.

`Python` · `XGBoost` · `Scikit-learn` · `Streamlit`
